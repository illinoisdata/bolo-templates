# Docling Layout Model

`docling-layout-old` is the old Layout Model of [Docling project](https://github.com/docling-project/docling).

This model uses the [RT-DETR](https://github.com/lyuwenyu/RT-DETR/tree/main/rtdetr_pytorch) architecture and has been trained from scratch on a variety of document datasets.
